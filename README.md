 Animal Intrusion System using ESP32

An IoT-based animal detection system that uses ESP32, PIR, Ultrasonic, and Piezoelectric sensors to detect animal intrusion. The system sends real-time alerts via Blynk, captures images using ESP32-CAM, and logs sensor data to ThingSpeak for remote monitoring. 

 Features:
- Multi-sensor animal detection
- Real-time Blynk notifications
- ESP32-CAM image capture
- ThingSpeak cloud monitoring
- Wi-Fi enabled remote access

 Technologies Used:
- ESP32
- ESP32-CAM
- PIR Sensor
- HC-SR04 Ultrasonic Sensor
- Piezoelectric Sensor
- Arduino IDE
- Blynk IoT
- ThingSpeak 

Result:

Successfully detects animal intrusion with real-time alerts, image capture, and cloud-based data logging for effective remote monitoring.
